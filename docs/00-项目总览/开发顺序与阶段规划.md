# 开发顺序与阶段规划

## 一、推荐开发顺序

1. 合同、客户、场站基础模型
2. 开工申请和服务记录
3. 开票、回款、应收计划
4. 预警规则
5. Excel 导入与报表

---

## 二、一期开发顺序建议

### 阶段 1：导入和字段补齐

- 补齐 04-10 关键字段建模
- 完成 06、05、04、09 的稳定导入
- 完成错误提示和导入预览

### 阶段 2：查询筛选重构

- 补全搜索视图
- 补全高级筛选字段
- 提升自定义筛选可用性
- 保存常用筛选

### 阶段 3：弱关联和后补关联合同

- 开工支持待关联合同
- 服务支持待关联合同
- 补关联合同后自动回填快照字段

### 阶段 4：导出和备份完善

- 按筛选结果导出
- 模块级导出模板
- 数据库备份方案

### 阶段 5：基础看板与统计

- 恢复稳定数据看板
- 合同、开票、回款、应收的基础分析

---

## 三、数据看板拆分实施顺序

### 第一阶段（当前）

- 数据看板拆成：全局概览 + 统一查询中心
- 先完成页面结构和菜单结构
- 不在这一阶段接大模型 API

### 第二阶段

- 统一查询中心增强
  - 条件联动
  - 结果摘要优化
  - 结果预览优化
  - 明细跳转优化

### 第三阶段

- 金额单位统一改造（元）
- 作为专项改造处理，不与别的功能混做

### 第四阶段

- AI 自然语言查询接入统一查询中心
- 由 AI 负责理解问题，系统负责执行结构化查询

---

## 四、数据完整性实施顺序

先不急着做最终导出模板美化，按下面顺序推进：

1. 导入正确
2. 页面正确显示
3. 列选择中字段完整
4. 完整导出可用
5. 最后再做贴近原台账样式的导出模板
