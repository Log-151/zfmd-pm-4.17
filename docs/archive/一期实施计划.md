# 一期实施计划

## 一期目标

先用系统替代最核心的 Excel 台账维护工作。

## 一期模块边界

### 必做

- 合同主档
- 开工申请
- 服务记录
- 开票登记
- 回款登记
- 应收计划
- 多条件筛选
- 基础导出

### 第二批再做

- 自动预警
- 自动统计报表
- Excel 历史数据导入
- 月度汇总
- 复杂审批流

## 推荐开发顺序

1. 合同、客户、场站基础模型
2. 开工申请和服务记录
3. 开票、回款、应收计划
4. 预警规则
5. Excel 导入与报表

## 当前假设

- Odoo 版本按 `17 Community` 先搭建
- 当前先做一个主模块 `zfmd_pm`
- 后续如果功能继续扩大，再拆子模块
