# 技能与插件建议

## 1. 现在是否必须增加 skills 或 plugins

结论：

`不是必须。`

当前这个项目最关键的不是额外技能，而是：

- 业务理解是否准确
- 字段映射是否完整
- 数据模型是否稳定
- 状态规则和预警规则是否正确

这些事情我现在已经可以继续完成，不需要你额外先安装技能或插件。

## 2. 什么情况下值得补充

如果后面进入这些阶段，补充工具会更有价值：

### 2.1 大批量 Excel 清洗和导入

如果后面你希望把多年历史台账更快导入系统，可以考虑：

- Python Excel 处理库
- 更强的数据比对脚本

### 2.2 自动化测试

如果后面系统开始稳定，需要减少 bug，可以补：

- Odoo 测试脚本
- UI 回归测试
- 导入校验脚本

### 2.3 报表和 BI

如果后面要做更强统计分析，再考虑额外工具会更合适。

## 3. 对当前阶段最有帮助的不是插件

当前阶段最能降低 bug 的做法是：

1. 先把字段和业务规则定准
2. 先做一版可用原型
3. 用真实样例数据跑一遍
4. 再补校验、自动规则和测试

## 4. 如果你真想加，我建议优先加什么

如果后面你愿意加能力，优先级建议是：

1. Excel 导入与清洗能力
2. 自动化测试能力
3. 报表导出能力

不是优先去装很多杂插件。

## 5. 当前最稳妥的做法

目前最稳妥的是：

- 不急着装额外 skills/plugins
- 先继续把 Odoo 原型做出来
- 等图形界面跑起来后，再判断哪些地方真的需要额外工具
