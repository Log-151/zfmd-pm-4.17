# 本地部署指南

## 环境要求

- Docker Desktop（已安装）
- Docker Compose（已安装）
- 项目路径：`~/temp/zfmd-pm-4.17`

## 启动步骤

### 1. 确保 Docker Desktop 正在运行

```bash
docker ps
```

### 2. 进入项目目录并启动

```bash
cd ~/temp/zfmd-pm-4.17
docker compose up -d
```

这会启动两个容器：
- `zfmd_pg` — PostgreSQL 数据库
- `zfmd_odoo` — Odoo 17 应用

### 3. 查看日志确认启动成功

```bash
docker compose logs -f odoo
```

看到 `Odoo server ready` 即表示启动成功。

### 4. 访问系统

浏览器打开 **http://localhost:8069**

## 演示流程建议

### 1. 先讲业务主线

系统以合同为主线，串联以下环节：

- 合同台账
- 开工申请
- 服务记录
- 开票登记
- 回款登记
- 应收计划
- 数据看板/统计

### 2. 先看合同台账

展示：合同编号、客户、场站、销售经理、产品线、合同金额、已开票、已回款、未回款。

### 3. 再看开工、服务、开票、回款、应收

按顺序展示，重点说明"选了合同之后，信息如何自动带出"。

### 4. 最后看统计/看板

- 执行中合同
- 超期服务
- 累计开票
- 累计回款
- 到期应收

## 数据拉通演示

### 场景一：从合同进入后续业务

1. 打开一条合同
2. 展示合同里的客户、场站、产品线、销售经理等信息
3. 进入开工申请或开票登记页面
4. 选择该合同
5. 展示系统自动带出相关字段

### 场景二：从合同反查后续执行情况

在合同页面展示：开工申请数量、服务记录数量、开票记录数量、回款记录数量、应收计划数量。

## 日常录入顺序

1. 先录合同台账
2. 有开工事项时录开工申请
3. 项目执行中录服务记录
4. 商务/财务录开票登记
5. 到账后录回款登记
6. 按合同条款维护应收计划
