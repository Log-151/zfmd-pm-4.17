# 导入底座实施清单（一期第一阶段）

## 一、第一阶段目标

一期第一阶段不追求一次性支持全部导入，而是先稳定打通四条最关键的数据链路：

1. `06 销售合同登记台账` -> 合同主档
2. `05 销售合同开发票登记台账` -> 开票记录
3. `04 销售合同回款登记台账` -> 回款记录
4. `09 执行中合同应收款明细台账` -> 应收计划

这四条链路打通后，系统就能先实现：

- 合同主线建立
- 开票、回款、应收挂到合同
- 支撑录入、查找和统计主需求

## 二、导入器统一能力要求

每个导入器都必须支持以下能力：

### 1. 文件选择

- 支持上传 Excel
- 明确识别对应模板类型

### 2. 预览导入

- 导入前先预览
- 显示识别出的字段、记录数、匹配成功数、未匹配数

### 3. 校验反馈

至少要提示：

- 缺少必填字段
- 合同匹配失败
- 金额或日期格式异常
- 重复记录

### 4. 正式导入

- 支持新增
- 支持按唯一键更新
- 支持重复导入时幂等更新

### 5. 导入结果报告

导入完成后显示：

- 成功多少条
- 失败多少条
- 哪几行失败
- 失败原因是什么

## 三、四类导入器的唯一匹配策略

## 1. 合同导入器（06）

### 唯一键

- `合同编号`
- 辅助键：`合同核心号`

### 导入目标

- 创建或更新 `zfmd.contract`
- 同时补齐客户和场站主档

### 关键规则

- 正式展示以完整合同号为准
- 导入时同时抽取合同核心号

## 2. 开票导入器（05）

### 唯一键

建议优先：

- `合同编号 + 开票日期 + 发票金额`

如果后续发现样例中重复率高，再补充：

- `合同编号 + 发票金额 + 发票单位 + 申请开票日期`

### 合同匹配顺序

1. 完整合同号
2. 合同核心号
3. 匹配失败进入错误报告，不强行导入为已关联合同

## 3. 回款导入器（04）

### 唯一键

建议优先：

- `付款单位 + 回款日期 + 回款总额 + 款项名称`

### 合同匹配顺序

1. 完整合同号
2. 合同核心号
3. 匹配失败时允许导入为 `待关联合同`

## 4. 应收导入器（09）

### 唯一键

建议优先：

- `合同编号 + 应收款项名称 + 应收时间 + 应收金额`

### 特别规则

- 汇总行和明细行必须区分
- 汇总行不进入正常应收统计
- 合同匹配失败时允许导入为 `待关联合同`

## 四、导入状态设计

所有导入对象建议统一具备以下概念：

- `已关联合同`
- `待关联合同`
- `导入失败`

这样后续开工、服务、开票、回款、应收都可以走同一套补关联合同逻辑。

## 五、第一阶段的系统实现建议

## 1. 不直接继续扩写旧脚本

当前 `scripts/import_contracts_from_06.py`、`import_demo_data.py` 这类脚本更适合做历史样例验证，
不建议直接拿来作为正式导入系统。

建议改成：

- 模块内正式导入服务
- 或模块内向导（wizard）

## 2. 正式导入结构建议

建议在 `zfmd_pm` 模块内新增：

- `models/import_job.py`
- `wizards/import_contract_wizard.py`
- `wizards/import_invoice_wizard.py`
- `wizards/import_payment_wizard.py`
- `wizards/import_receivable_wizard.py`

每个向导负责：

- 上传文件
- 预览
- 校验
- 正式执行

## 3. 第一阶段最小落地版

如果考虑开发效率，第一阶段可先做：

- 先保留 Python 脚本解析 Excel
- 但通过 Odoo 内的按钮或向导来调用
- 先不追求最复杂的拖拽导入体验

也就是说：

- 先把“能稳定导入、能提示错误、能重复导入”做出来
- 再逐步提升交互体验

## 七、第一阶段开发顺序

### 步骤 1

补齐合同模型中的 `合同核心号` 等导入关键字段，统一匹配规则。

### 步骤 2

完成 `06` 合同导入器，确保：

- 合同主档能稳定导入
- 客户、场站能正确建立或更新

### 步骤 3

完成 `05` 开票导入器，确保：

- 能按合同号或核心号关联
- 导入失败行有清晰反馈

### 步骤 4

完成 `04` 回款导入器，确保：

- 回款总额自动计算
- 能进入待关联合同状态

### 步骤 5

完成 `09` 应收导入器，确保：

- 汇总行与明细行正确区分
- 状态判断稳定

## 八、第一阶段完成标志

满足以下条件即可视为一期第一阶段完成：

- 06、05、04、09 四类表格都能批量导入
- 导入失败时能准确提示原因
- 合同号全称和核心号两套匹配规则能跑通
- 导入后在系统里能按合同查到开票、回款、应收关联信息
- 可重复导入而不产生大量重复脏数据
