# 测试与回归清单

## 一、执行原则

- 所有新功能先在本地验证，再决定是否阶段性上云。
- 每次改动后，至少做一次模块升级、一次浏览器强制刷新、一次业务回归。
- 导入功能必须同时验证：
  - 预览导入
  - 正式导入
  - 重复导入
- 所有金额字段统一按 `万元` 验证。
- 所有导入字段都要优先保证“原文不丢失”，再验证结构化字段是否正确。
- 任何一次导入完成后，都必须确认：
  - 记录数正确
  - 关键字段值正确
  - 原文字段可追溯
  - 导出备份可回表

## 二、每次开发后的固定操作

1. 本地升级模块

```powershell
docker exec zfmd_odoo sh -lc "odoo -d zfmd_pm -u zfmd_pm --stop-after-init"
```

2. 重启本地主容器

```powershell
docker restart zfmd_odoo
```

3. 关闭当前所有 Odoo 页面标签
4. 重新打开本地地址
5. 浏览器执行 `Ctrl + F5`
6. 重新登录 `zfmd`

## 三、页面回归清单

每次升级后，至少逐个打开并确认页面能正常进入：

- 数据看板
- 合同台账
- 开工申请
- 服务记录
- 开票登记
- 回款登记
- 应收计划

重点检查：

- 页面能否正常打开
- 不出现 Odoo 客户端错误
- 列表表头是否正常中文
- 列选择中的新增字段是否可见
- 导入入口是否仍在对应模块内部

## 四、导入回归清单

### 1. 06 合同导入

检查项：

- 预览识别数是否正确
- 正式导入数是否正确
- 合同导入顺序是否与 Excel 顺序一致
- 金额字段是否按 `万元` 正确写入
- 客户、场站、销售经理、产品线等字段是否与原表一致
- 导入后导出时，表头是否齐全

### 2. 05 开票导入

检查项：

- 小批量导入是否成功
- 正式导入数量是否与预期一致
- 合同编号是否能匹配到已有合同
- 未匹配合同时，来源合同号是否保留
- 开票金额、实际回款金额是否与原表一致，单位为 `万元`
- 导入后合同主线中的开票统计是否同步

### 3. 04 回款导入

检查项：

- 小批量导入是否成功
- 合同编号列是否正确显示
- 来源合同号是否保留
- 回款金额、汇票回款、现金回款是否与原表一致，单位为 `万元`
- 回款项名称、付款单位、销售经理是否与原表一致

### 4. 09 应收导入

检查项：

- 是否正确过滤：
  - `合计`
  - `总计`
  - `汇总`
  - `小计`
  - 空白说明行
- 导入数量是否与真实业务记录数一致
- 应收金额、实际回款金额是否与原表一致，单位为 `万元`
- 导入结果摘要是否统一显示：
  - 识别记录数
  - 导入成功数
  - 未匹配合同数
  - 跳过/问题记录数

### 5. 07 开工申请导入

检查项：

- 原文字段是否保留
- 规范化日期字段是否在可解析时正确写入
- 关键编号、客户、场站、销售经理是否与原表一致
- 预计合同金额、预计成本、实际合同金额是否按 `万元` 正确写入

### 6. 08 气象服务记录导入

检查项：

- 第一张表字段是否导入
- 第二张表“其他信息”字段是否导入
- 原文字段是否保留
- 规范化日期字段是否在可解析时正确写入
- 以下字段是否可在列表或详情中看到：
  - 记录日期
  - 续签前服务到期时间
  - 续签后服务开始时间
  - 中断期间服务费如何处理
  - 备注

## 五、数据正确性清单

所有导入功能都必须检查：

- 时间是否与 Excel 一致
- 人名是否与 Excel 一致
- 钱数是否与 Excel 一致
- 金额单位是否统一为 `万元`
- 合同编号是否与 Excel 一致
- 原文字段是否保留
- 空值是否来自原表，而不是系统误写

## 六、导出与备份清单

后续每个模块都必须补齐“完整导出/备份”能力，验收时至少检查：

- 导出的表头是否尽量与原始样例表一致
- 导出的字段是否齐全，不丢关键列
- 金额字段是否统一以 `万元` 展示
- 原文字段是否可导出
- 导出后的 Excel 是否能用于人工核对和恢复

## 七、问题定位顺序

如果出现“有时好使、有时突然不好使”，按下面顺序排查：

1. 是否已经升级模块
2. 是否已经重启容器
3. 是否浏览器还拿着旧缓存
4. 是否旧测试数据未清空
5. 是否视图已更新但数据库未同步
6. 是否导入器逻辑与当前样例表头不一致
7. 是否源文件本身存在乱码或字段定义错误

## 八、当前阶段的发布纪律

- 本地不通过，不上云。
- 没做完回归，不给客户演示。
- 导入功能没有经过“小样本 + 完整样本 + 重复导入”三轮验证，不进入下一阶段。
- 导出/备份没有达到“表头完整、数据完整、金额单位统一、可回表”要求，不算完成。
