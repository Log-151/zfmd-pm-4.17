# 图形界面原型里程碑

## 1. 什么时候可以开始看图形界面

对当前项目，图形界面分为三个层次。

### 第一层：基础后台界面

时间点：

- 现在代码上已经具备基础条件
- 只要本机 Docker daemon 启动
- 并把 Odoo 服务拉起来

可看到的内容：

- 左侧菜单
- 合同列表
- 开工申请列表
- 服务记录列表
- 开票登记列表
- 回款登记列表
- 应收计划列表
- 对应录入表单

这时就已经能根据真实界面讨论功能。

### 第二层：适合讨论的原型界面

时间点：

- 在基础后台界面跑起来之后
- 再补充：
  - 演示数据
  - 首页看板
  - 更清晰的表单分组
  - 常用筛选器

可讨论内容：

- 菜单是否合理
- 字段是否缺失
- 哪些字段应隐藏或自动带出
- 哪些列表需要默认展示
- 哪些预警要放首页

### 第三层：接近可用版本

时间点：

- 导入历史 Excel
- 加入自动预警和统计
- 完善状态规则

可讨论内容：

- 月报、季报导出
- 回款和应收是否准确
- 预警是否符合业务
- 管理层统计看板是否够用

## 2. 当前离图形界面还差什么

当前代码已经具备：

- 模型
- 菜单
- 表单
- 列表
- 搜索筛选

当前还差的主要不是代码，而是运行环境：

- Docker Desktop / Docker daemon 需要启动

只要环境起来，我就可以继续帮你：

- 启动 Odoo
- 安装模块
- 进入浏览器界面
- 再根据页面继续改

## 3. 建议的下一步

最合理的顺序：

1. 继续补首页和演示数据
2. 启动 Odoo
3. 进入界面一起看
4. 再按你的反馈调整字段和流程
