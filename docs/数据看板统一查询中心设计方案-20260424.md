# 数据看板统一查询中心设计方案

日期：2026-04-24

## 一、目标

把当前“数据看板”从旧的指标展示页升级为统一查询中心，先实现以下四项基础能力：

1. 统一条件区  
2. 统一结果区  
3. 统一导出  
4. 结果跳明细

本阶段不接入大模型自然语言查询，后续作为二期能力规划。

## 二、使用方式

业务人员在数据看板中：

1. 选择查询对象  
2. 输入筛选条件  
3. 点击“应用查询”  
4. 在看板里查看结果摘要  
5. 点击“查看结果明细”跳到对应台账  
6. 点击“导出当前结果”导出当前查询结果

## 三、统一条件区

第一版统一条件区包含：

- 查询对象
- 开始日期
- 结束日期
- 关键词
- 合同编号
- 客户/付款单位
- 付款单位（回款专用）
- 场站
- 销售经理
- 省区
- 集团
- 产品线
- 状态

说明：
- 各台账共用一套条件字段
- 不适用的字段会被忽略，不参与当前查询

## 四、统一结果区

第一版统一结果区展示：

- 结果对象
- 匹配记录数
- 金额口径
- 汇总金额
- 最近查询时间
- 结果摘要

## 五、统一导出

导出当前结果时：

- 沿用当前查询条件
- 调用各业务台账已有的正式中文导出逻辑
- 金额字段保持“万元”口径

## 六、结果跳明细

点击“查看结果明细”后：

- 自动打开对应台账
- 自动带入当前查询条件
- 用户可继续筛选、预览、导出

## 七、第一版支持的查询对象

- 合同台账
- 开工申请
- 服务记录
- 开票登记
- 回款登记
- 应收计划

## 八、第二阶段规划

后续在本方案稳定后，再继续推进：

1. 条件联动优化  
2. 常用查询模板  
3. 统一透视与图表分析  
4. 大模型自然语言查询助手
