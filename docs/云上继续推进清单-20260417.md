# 云上继续推进清单

## 当前状态

- 阿里云 Ubuntu 服务器已跑通 Odoo 基础环境
- `ZFMD Project Management` 模块已能进入安装阶段
- 当前云上版本和本地版本还未完全对齐

## 总体策略

分两条线推进：

1. 本地版作为客户演示和需求确认主环境
2. 云上版作为持续收口和后续对外访问环境

## 云上优先级

### 第一优先级：恢复业务账号视图

目标：

- 只保留 `admin` 和 `zfmd`
- `zfmd` 登录后只看业务菜单
- 不再依赖后台手工勾权限

### 第二优先级：恢复之前已完成的界面收口

目标：

- 去掉无关系统入口
- 顶部右侧只保留必要项
- 登录页和系统标题恢复业务化展示

### 第三优先级：恢复首页看板和统计

目标：

- 在不影响安装稳定性的前提下把看板单独补回
- 重点先恢复最核心指标，而不是一次做复杂大屏

### 第四优先级：导入与数据校验

目标：

- 先在本地确认字段映射和导入逻辑
- 再迁移到云上

## 为什么云上要慢一点

因为当前云上不是简单的“代码复制”，还涉及：

- 新数据库初始化
- 新环境权限
- 新环境安装链路
- 页面和前端收口是否与服务器版本兼容

先用本地版承接客户演示，是更稳的做法。
