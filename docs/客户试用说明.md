# 兆方美迪项目管理系统客户试用说明

## 试用目标
- 本次试用主要用于确认系统设计方向是否符合贵方业务需求。
- 当前版本重点展示 `合同 -> 开工申请 -> 服务记录 -> 开票登记 -> 回款登记 -> 应收计划 -> 数据看板` 的业务主线。

## 建议试用路径
1. 先打开 `数据看板`，整体了解合同、服务、开票、回款、应收之间的关系。
2. 进入 `合同台账`，查看合同主档是否已覆盖日常管理所需的核心字段。
3. 分别查看 `开工申请`、`服务记录`、`开票登记`、`回款登记`、`应收计划`，确认模块之间是否符合业务衔接逻辑。
4. 回到 `数据看板`，查看是否能形成管理分析视角。

## 本轮建议重点关注
- 字段是否完整：是否覆盖现有 Excel 台账里的必要信息。
- 页面是否易用：录入顺序是否自然，列表是否便于筛选和查找。
- 数据是否拉通：选择合同后，后续业务单据是否应自动带出相关信息。
- 看板是否有价值：当前统计口径是否能支持日常管理。

## 试用反馈建议
- 哪些字段必须保留。
- 哪些字段可以隐藏。
- 哪些模块名称或表头名称需要调整。
- 哪些统计指标必须上首页。
- 哪些原 Excel 工作内容目前系统里还没有体现。
