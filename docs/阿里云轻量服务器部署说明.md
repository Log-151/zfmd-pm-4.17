# 阿里云轻量服务器部署说明

## 适用场景

本文档适用于：

- 阿里云轻量应用服务器
- Ubuntu 22.04
- 使用 Docker Compose 部署兆方美迪项目管理系统

相比 Railway，阿里云服务器更适合当前这个 Odoo 项目，因为：

- Odoo 依赖 PostgreSQL、附件目录、初始化数据库和持久化目录
- 服务器环境更可控
- Docker Compose 更适合 Odoo 这种有状态系统

## 一、服务器建议

当前服务器配置：

- 2 vCPU
- 2 GiB RAM
- 40 GiB ESSD

结论：

- 作为演示环境、内部试用环境：可以使用
- 作为正式多人生产环境：建议后续升级到 4 GiB RAM 及以上

## 二、准备内容

确保服务器已经具备：

- Ubuntu 22.04
- 可以 SSH 登录
- 已开放安全组端口：
  - `22`
  - `80`
  - `443`
  - `8069`（如需直接访问 Odoo）

## 三、部署推荐目录

建议在服务器上使用这个目录：

```bash
/opt/zfmd-pm
```

## 四、安装 Docker 和 Docker Compose

在服务器执行：

```bash
sudo apt update
sudo apt install -y ca-certificates curl gnupg lsb-release
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
sudo chmod a+r /etc/apt/keyrings/docker.gpg
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu \
  $(. /etc/os-release && echo \"$VERSION_CODENAME\") stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo systemctl enable docker
sudo systemctl start docker
docker --version
docker compose version
```

## 五、拉取项目代码

```bash
cd /opt
sudo git clone https://github.com/Log-151/zfmd-pm-4.17.git zfmd-pm
cd /opt/zfmd-pm
```

如果目录已经存在：

```bash
cd /opt/zfmd-pm
git pull
```

## 六、首次启动

先直接使用仓库里的本地部署结构：

```bash
cd /opt/zfmd-pm
docker compose up -d
```

查看状态：

```bash
docker compose ps
docker compose logs -f odoo
```

## 七、访问系统

如果服务器公网 IP 是 `8.215.67.224`，可直接打开：

```text
http://8.215.67.224:8069
```

如果页面打不开，请检查：

- 阿里云轻量服务器防火墙
- 服务器系统防火墙
- Docker 容器是否已正常启动

## 八、初始化数据库

首次进入 Odoo 后：

1. 创建数据库
2. 管理员主密码使用当前配置文件中的 `admin_passwd`
3. 创建管理员账号
4. 登录后安装 `zfmd_pm` 模块

如果要更干净地初始化，也可以后续改用自定义数据库名，如：

- `zfmd_pm`

## 九、建议后续优化

第一阶段先跑通：

- Odoo
- PostgreSQL
- 自定义模块
- 演示账号

第二阶段再补：

- Nginx 反向代理
- 域名
- HTTPS
- 自动备份

更建议：
